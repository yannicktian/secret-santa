Points d'attention

  • Pas encore vu pour de vrai : l'écriture dans la base de production avant ton constat (seules des lectures ont été faites par les agents) ; le champ et le bouton au-dessus du clavier sur un vrai téléphone (essayé dans Chromium seulement).
  • Adresse de production : elle n'est plus dans le dépôt, devenu public ; les anciennes adresses, visibles dans l'historique, répondent 404.
  • Limites acceptées : qui a le mot de passe d'administration peut voir un tirage en effaçant et en rechoisissant un mot de passe ; n'importe qui peut savoir qui a choisi le sien. Choisis un mot de passe d'administration long.
  • Rares erreurs passagères : deux « Refaire le tirage » au même moment pendant un choix de mot de passe (« Réessayer » corrige) ; un essai raté pendant un tirage refait peut laisser une minute de blocage.
  • Base : à San Francisco (sfo1, gardée sur ta réponse), sans région de lecture d'après Vercel (non vu dans la console Upstash) : la garantie du tirage en dépend.
  • Node : 26 en CI et en production, 24 sur orca-server (avertissement attendu).
